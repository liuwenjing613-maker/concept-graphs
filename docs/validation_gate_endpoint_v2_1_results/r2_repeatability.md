# R2 endpoint 复核一致性

口径：**同一复核者重复稳定性（intra-rater）**

- R2 案例数：24
- 证据充分性一致：23/24 = 0.958333
- 最终状态一致：20/24 = 0.833333
- 最终状态 Cohen's kappa：0.705521
- 三字段完全一致：19/24 = 0.791667
- 两轮都判 WRONG 时错误类型一致：9/10 = 0.9
- 有任一字段变化的案例：5
- R1 WRONG 保持 WRONG：10/10

## 应如何解释

R2 只检验同一证据、同一简化字段在第二次判断时是否稳定。它不重新估计 97 个 endpoint 的错误率，也不验证阶段根因或修复动作。

若 R1、R2 都由同一人完成，本结果不能写成 inter-rater reliability。两轮间隔很短时，还应明确说明记忆可能使一致率偏高。
