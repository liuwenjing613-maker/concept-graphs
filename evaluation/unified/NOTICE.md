# Third-party evaluation engine

`ovimap_ap_pinned.py` is copied without modification from the OVI-MAP evaluation engine at commit `f8f7bcd0ca8228f6b8b4064f2e29dcee3a502424`. Its license is retained in `OVIMAP_LICENSE.txt`. The wrapper sets the class list, overlap thresholds and minimum region size at runtime.

Ground-truth arrays, meshes, embeddings and experiment maps are external data, not included in this code package.
