# v5 visual test examples

本分支仅保存 **v5 的 337 个观测审核案例**，以原始输入图片为主；不包含 v6 反投影或斜线版图片。

- 图片：**1,443 张 JPEG**，总计 **199.30 MiB**，最大单张 **266.22 KiB**。
- 图像保持源文件字节不变，未重新压缩。每张图片的 SHA256、尺寸及实际输入顺序保存在各案例的 case.json。
- 人工参考：130 例已确认，202 例历史参考，5 例暂不能定论。全部图片保留，后者明确排除于评测；参考标签不是数据集 GT。
- 这是同一 room0 场景的历史冻结案例，不是新的在线建图运行，也不代表独立泛化评测。

[浏览全部案例](CASES.md) · [机器可读清单](manifest.json) · [来源说明](NOTICE.md)

每个案例目录中的 README 可直接在 GitHub 浏览全部输入图。case.json 保存图序、合法选项、原 v5 输出的可读选择与格式状态，以及当时实际请求使用的提示词引用和模型参数。

示例：[f000012_d001_create](cases/f000012_d001_create/README.md) · [f000004_d020_create](cases/f000004_d020_create/README.md)

## 目录

- cases/<case_id>/*.jpg：原始 VLM 输入图片。
- cases/<case_id>/case.json：经过字段筛选的可移植元数据。
- prompts/：这批 v5 历史请求实际使用的 system 提示词；不是后续 v6 的提示词。

参考版本：v5_human_reference_review2_20260906。没有重新推理、修改人工标签或混入 v6 结果。
文件中不包含服务端绝对路径、API 地址、凭据或 Base64 图片请求体。

本分支采用普通 Git 保存这份固定快照，便于直接浏览和克隆，不需要 Git LFS。
