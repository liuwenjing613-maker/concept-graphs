# v7_1

基于 v7_VLMsplit_image / fbd00e0，在独立工作树运行。目标是提高未解决事件的处理质量；尚未证明达到人工准确率。

## 正式默认变更与实验功能

正式默认只启用未知计票、历史等待与截断恢复。联合复核两轮真实smoke都出现局部/整体误判，虽然正面合并保护可以阻止该例错误，但尚无可靠纠错证据，因此默认关闭，不能据此宣称改判成功。以下第3、4条仅为实验开关 `V7_1_JOINT_REVIEW=1`，本次完整对照不启用。

1. auto 下污染、不确定、输入/调用失败、否定身份与 >90% 点云包含冲突：当次仍不合并，但记为 UNRESOLVED，不累计明确否定票，并中断连续合并票。明确不同累计两次才锁定；明确相同仍连续两次才批准。
2. 视觉 UNRESOLVED 在所选历史观测 UID/mask 未变化时等待，不重复调用。不是负面身份锁定；不缓存答案计票。历史变化后恢复审核，真实对象合并仍改变 generation。单纯几何更新不解除等待；此限制需结合最终召回分析。技术失败不进入这种历史等待，可在之后事件重试。
3. 多 SAME 且未全部获批时，增加一次联合复核：原当前/候选卡 + 各节点最多三张质量/异常历史，全部来自当前冻结 H。新证据子快照记录 parent H、对象版本、历史选择、mask/image 哈希及 C 绑定。只在当前可用、唯一候选 SAME/SAME_OBJECT_PART 且 CLEAN、其他候选全部明确 DIFFERENT 时，允许当前观测关联这个原 SAME 候选。不会据此合并节点或增加合并票。
4. 同一物体的局部/整体显式输出 SAME_OBJECT_PART，不能按覆盖范围拆成不同实例。同一帧合并身份明确 SAME 的候选对受保护，联合选择不能反向覆盖；如果全部冲突对都是正面确认未达到两票，直接等待，不额外询问。
5. 输出 length 截断时，仅补一次双倍输出预算请求，保持同一 H；所有请求共同最多四次超时。格式失败与语义不确定不无限重问。每次尝试及其 num_predict 单独保存，逻辑阶段只提交一次。

YOLO 原图 imgsz=1200/rect=True、SAM/CLIP、原四阶段提示词、候选数、90%阈值、距离、检测过滤和主图在线顺序保持不变。当前观测质量不足仍丢弃；不在本版加入分割修复、节点拆分、未来帧待决队列。

## 运行

服务器目录：`/home/chenkejun/beauty/conceptgraphs/code/experiments/v7_1`

仅建图：

```bash
bash run_v7_1.sh auto
bash run_v7_1.sh human
```

固定 room0 对比实验（空图400帧 + strict audit + 语义/实例PQ/几何覆盖评测 + 对比文件）：

```bash
bash run_v7_1_experiment.sh
```

后者自动生成唯一输出名，复用 `v7_auto_image_detections` 逐帧检测，拒绝复用已有地图。默认 GPU1。

当前验证可用的默认 VLM 接口为 11464、11463，最多支持三个。11435拒绝连接；11436虽能列模型，实测图片请求视觉编码器加载失败，未带入正式实验。可用 `--vlm-urls` 为仅建图入口指定经真实图片验证的1–3个接口。三个同模型服务不等于独立专家。

## 实验依据与验收

主要对照 v7_auto_image：mIoU35.1341、fwIoU69.0959、PQ49.0282、RQ57.5342、SQ85.2157、5cm覆盖97.0550（百分数），97个最终节点。对应同一固定支撑及类别排除口径。PQ为诊断指标，不是官方Replica PQ。

本版采用相同原图检测缓存；主图只读取当前帧的缓存，从空图按0..399处理。GT仅供建图完成后的评测进程，VLM不会看到GT或未来帧。

smoke/回归记录：`/home/chenkejun/beauty/v7_1_20260909/`。第一轮smoke暴露11436服务故障；第二轮联合模型输出把局部与整体分开，不能算纠错成功，已补正面合并保护与显式局部关系。最终smoke及完整实验分别保留，失败不删除。

完整实验 `state.json` 记录进程、各阶段、返回码与耗时；`baseline.json` 固定旧结果；`comparison.json/md` 给出差值。对比需同时看PQ与语义指标、FP/FN、逐类退化；不得只以改判数量/审计通过宣称准确率提高。新旧并发接口数不同、旧版现场检测而本版复用缓存，总耗时不能完全归因于策略。
